Peridotbase is a relational database that lives entirely on Solana. Tables, rows, indexes, and access rules are accounts owned by the Peridotbase program — no off-chain server, no canonical database copy, and no custodian holding your data.

The Studio in this repository is the browser front end for that program. It connects to your Solana wallet, talks to an RPC endpoint you choose, and renders the database through the Peridotbase TypeScript SDK.

## How the pieces fit

- **`peridotbase-core`** — the on-chain Rust program (kept in its own repository). It owns the account layout, instructions, and access rules.
- **`@peridotvault/peridotbase-sdk`** — the TypeScript client the Studio uses. It defines the transport, wallet, and RPC ports, plus the protocol types shared by every screen.
- **Peridotbase web** — one React app in `apps/web`: prerendered marketing pages plus the Studio under `/studio`. The Studio is a pure client: SDK calls, Solana RPC health checks, and Wallet Standard signing.
- **Documentation** — the site you are reading, built with Mintlify from `apps/docs`.

## Current status

The Studio shell, wallet connection, RPC health check, and the full table/query interface are in place, and the program is deployed on devnet. Reads, writes, DDL, queries, indexes, and live refresh run against it. Operations the program has no instruction for stay visible but report that they are pending integration instead of pretending to succeed.

<Note>
	Peridotbase never asks for a seed phrase or a private key. Wallet Standard hands the Studio a
	public address and asks the wallet extension to sign when an instruction needs it.
</Note>
